# Stockeasy 首版设计

用户已选择并授权直接制作推荐的本地看板，先看效果再优化，并将代码同步到公共仓库 chandler0714/stockeasy。

## 目标与方案
Python + Streamlit 本地单用户看板，AKShare 获取 A 股、境内 ETF、场外基金；yfinance 获取港美股和海外 ETF。相比仅提供数据接口，该方案可直接查看效果；相比独立前后端，首版维护和启动更简单。暂不提供交易、账户连接或公网部署。

## 功能
- 深色侧栏、浅色内容区，中文自选列表、市场筛选、行情指标、历史价格/成交量、区间收益与回撤、CSV 导出。
- 支持添加/删除自选、选择日期和复权口径，设置定时刷新。
- SQLite 本地历史缓存、行情缓存与自选持久化；首次取完整区间，后续更新最近区间。
- 每条数据说明来源、币种、市场时间和获取时间。失败回退缓存并明确提示；不将历史收盘价标记为实时。
- 演示模式使用固定种子生成的合成数据，并在显著位置标注；与真实缓存完全隔离。
- 场外基金显示已公布单位净值，分析不将未复权净值误称分红再投收益。

## 实施选择
Python >=3.11；Streamlit、pandas、Plotly、AKShare、yfinance；默认以真实数据启动，可显式切换演示。自选初始覆盖 A 股、境内 ETF、港股、美股、基金。免费上游不承诺固定时延；使用受限超时与本地缓存保护界面。

## 验收
核心计算、标准化、失败回退、模式隔离和持久化测试通过；Streamlit 测试及浏览器人工操作正常；实际请求探测记录成功或限制；不发布本地数据库、密钥、虚拟环境和下载的行情。最终打开本地预览并同步代码到指定仓库。
