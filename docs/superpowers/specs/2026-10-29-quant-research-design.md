# 三库量化研究集成

用户要求将此前推荐的 1 QuantStats、2 Backtesting.py、3 PyPortfolioOpt 集成到现有工具，并说明 WhaleQuant 学习方法。保留本地深色 PC 看板、现有数据适配/缓存与公共源码同步；不接入交易或券商账户。

## 方案
新增“量化研究”页面，三个标签分别承载收益体检、策略回测、组合配置。使用现有自选及基础观察池，显式点击运行；行情自动刷新不重算研究任务。结果与模式/产品/日期/参数绑定，变更输入不复用旧结果。

- 收益体检：QuantStats 计算年化收益、波动、夏普、最大回撤、月度表现与基准对照；可生成完整 HTML 报告。基准限定相同币种、按共同观测日期计算，不前向填补缺失。基金单位净值仅表示价格表现，明确未计分红再投。
- 回测：Backtesting.py 运行均线交叉、趋势延续、回撤修复三种可解释规则；长仓、下一根日线开盘成交、可设初始资金、每边手续费、价差、每手数量与资金使用比例。只接收完整 OHLC 的股票/ETF；不伪造基金 OHLC。展示净值、对照曲线、闭合交易记录及未平仓数。披露没有完整模拟停牌/涨跌停排队/税费/真实成交条件；最后持仓不强制平仓。
- 配置：PyPortfolioOpt 最小波动或最大夏普，同币种股票/ETF，2～8 个产品，权重上限。前 80% 日期拟合均值与收缩协方差，后 20% 留出检验初始固定份额组合，对照等权。展示权重、相关性、模型估计与留出表现。不能把样本内优化曲线当收益预测。场外基金待总收益净值完善后再纳入配置。

## 质量要求
价格必须正、有限，日期去重排序；不允许跨币种无汇率拼接。报告/组合数据不足或请求失败明确报错，不静默删掉资产。训练和检验按时间分开，未来价格不得进入训练或交易信号。演示/真实结果隔离，带来源、获取时间与价格口径；导出默认仅在本机生成。

## 学习说明
依据 WhaleQuant 当前 README 的八章内容，给出分阶段练习路线。其 README 标注 Alpha、依赖 Python 3.9；不向当前 Python 3.12 工具环境安装课程旧 requirements，不复制非商业课程内容到项目。

## 验收
真实调用三库的计算/边界测试、AppTest 运行与导出流程、既有回归、浏览器深色页面检查、一轮独立审查。完成后同步指定仓库，最终说明使用方式与已知模型限制，并给学习路线。
