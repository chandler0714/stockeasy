# ↗ Stockeasy

一个在本机运行的中文 PC 市场工作台。用腾讯财经获取股票/ETF 报价快照，AKShare 和 yfinance 获取历史数据；中间展示可解释的当日推荐与风险，右侧常驻自选和可添加的产品列表。建议 1440px 以上宽屏使用。

默认采用深色主题，卡片、表单、下拉框、数据表和图表同步适配；涨跌继续采用红涨绿跌。

## 快速开始

推荐 Python 3.12（最低 3.11）。在项目目录运行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows 激活命令为 `.venv\Scripts\activate`。

打开 <http://127.0.0.1:8501>。默认连接真实数据；首次加载需要等待上游响应。无需 API 密钥。

**先看界面效果：** 打开 <http://127.0.0.1:8501/?demo=1>，或开启左侧「演示模式」。演示价格和图表是合成数据，不能用作市场判断；关闭开关恢复真实数据。

## 首版功能

- **当日推荐：** 观察池内按趋势延续、量能变化、回撤修复、低波动分组；每张卡片有数值理由、近 60 个数据点走势、数据截止日、来源和观察风险。可以直接查看历史走势或加入自选。
- **右侧自选：** 已选与发现分开显示；一键添加、移除、查看走势，支持输入其他证券代码。发现列表是固定观察池，不表示这些产品已满足推荐条件。
- **核心方向：** 沪深300、创业板、黄金和标普500 ETF 的代理行情，明确区分于指数点位；涨跌统计仅代表有效自选样本。
- **风险观察：** 距近 60 个数据点高点回撤 ≥15%、年化波动 ≥35% 时展示提示，并保留价格截止日。数据不足时不输出“无风险”结论。
- A 股、境内 ETF、港股、美股及海外 ETF、境内场外基金的自选列表，最多 20 个标的。
- 股票/ETF 行情快照默认每 5 秒轮询，可选 15 / 30 / 60 / 120 / 300 秒或暂停；显示最近检查时间。日线筛选独立更新。
- 历史日线、价格曲线、成交量、K 线和自定义日期。
- 区间涨跌幅、最大回撤、年化波动率，以及收益/回撤曲线。
- 原始价格、A 股/ETF 前后复权、Yahoo 复权；基金使用单位净值。
- CSV 包含市场、币种、价格口径、数据来源和获取时间。
- SQLite 本地缓存和自选持久化；失败回退缓存并标注原获取时间。

## 量化研究

左侧进入「量化研究」，三个标签共用现有自选、观察池和历史缓存。选择参数后点击运行；行情自动刷新不会重算研究。更改产品、模式或参数后需重新运行，结果下方可查看来源、实际覆盖区间和缓存状态。

| 标签 / 引擎 | 可以做什么 | 主要口径 |
| --- | --- | --- |
| 收益体检 / QuantStats | 区间与年化价格回报、回撤、波动、夏普、Sortino、月度表现、同币种基准对照；指标 CSV 和完整 HTML 报告 | 按共同有效日期，不填补缺失价格；年化按 252 个观测期；不扣个人交易费 |
| 策略回测 / Backtesting.py | 均线交叉、趋势延续、回撤修复；设置资金、手续费、价差、每手数量与资金使用比例；交易记录、净值 CSV | 股票/ETF 完整 OHLC 日线；信号后下一根日线开盘成交；只做多，末日持仓不强制平仓 |
| 组合配置 / PyPortfolioOpt | 同币种 2～8 个股票/ETF；最小波动或最大夏普；权重上限、相关性和理论配置金额；权重 CSV | 前 80% 共同日期拟合、后 20% 留出；固定初始份额持有，对照等权；未计交易费 |

先用「演示模式」熟悉流程，再切换真实数据。真实模式不会在连接失败时自动替换为演示结果。收益体检至少需要 30 个共同价格点；组合至少需要 100 个。基准是可修改的研究参照，并非基金合同基准。

QuantStats 当前通过数值推断价格或收益率。为防止极端区间被误读，单个共同观测区间涨幅 ≥100% 时，本工具明确停止体检与 HTML 报告生成，提示检查复权和日期缺口；不输出互相矛盾的指标。

回测包含设定的每边手续费与价差，未完整复现停牌、涨跌停排队、税费、逐笔滑点和各市场交易规则；每手数量需按具体产品核对。复权价格是研究价格，不能把回测账本当历史真实成交记录。起始预热期可能持有现金，而买入持有参考从区间首日开始、不扣费用。开盘跳空可能导致资金不足而拒单。

场外基金可做单位净值体检，但未计分红再投，不等于实际投资总收益；当前不参与交易回测或组合优化。组合模型估计不代表未来收益，留出区间也不保证未来有效。工具不连接交易账户。

## 配合 WhaleQuant 学习

课程：[GitHub 源码](https://github.com/datawhalechina/whale-quant) / [在线阅读](https://datawhalechina.github.io/whale-quant/)。下面是结合本工具的原创练习顺序，每周约 5 天、每天 45～60 分钟，可按基础放慢：

| 阶段 | 阅读范围 | 在 Stockeasy 上完成的练习 |
| --- | --- | --- |
| 第 1 周 | 第 1～2 章，投资、量化与市场基础 | 区分价格、收益、回撤、波动和基准；选一个宽基 ETF，解释体检页每个指标 |
| 第 2 周 | 第 3 章，股票数据获取 | 在深度分析导出日线，检查日期、复权、缺失与成交量，独立计算 20 日均线 |
| 第 3 周 | 第 4 章，量化选股 | 固定观察池，记录推荐理由；区分信号筛选与未来收益，避免只研究今天仍存续的赢家 |
| 第 4 周 | 第 5、7 章，择时与回测 | 运行均线基线，手工核对 3 笔交易的信号日、次日成交与费用；只改一个参数，再看未参与调参的区间 |
| 第 5 周 | 第 6 章，调仓 | 选 2～4 个同币种 ETF，比最小波动与等权；解释相关性、上限、训练/留出差异。当前工具演示固定份额，并未实现定期调仓 |
| 第 6 周 | 第 8 章，机器学习，可选 | 先能解释基线，再做简单预测；按时间划分训练/验证/测试，不反复调参看测试集；当前工具不包含 ML 训练 |

每次练习记录：问题 → 数据区间/来源 → 一个假设 → 参数与费用 → 结果 → 为什么可能失效。Python 较生疏时先补 pandas 的索引、筛选、收益率和 rolling，不必急着读机器学习。

课程 README 当前仍标注 Alpha 和 Python 3.9.X 的旧依赖。先在线阅读；需要复现原 notebook 时另建学习环境，不要将课程旧 requirements 安装到本项目的 Python 3.12 环境。课程内容遵循其 CC BY-NC-SA 4.0 许可；本项目仅链接课程，不复制其代码或教材。

## 数据覆盖与限制

| 范围 | 接入 | 说明 |
| --- | --- | --- |
| A 股 | 腾讯报价；AKShare → 东方财富历史 | 单证券报价快照，失败后尝试原东方财富通道；源时间与获取时间分开显示 |
| 境内 ETF | 腾讯报价；AKShare 历史 | 报价明确区分沪深市场，失败后尝试东方财富单证券报价，避免每次下载全部 ETF |
| 港股 / 美股 / 海外 ETF | 腾讯报价；yfinance → Yahoo 历史 | 报价可能延迟，非交易时段显示最近可用价格；腾讯失败后尝试原 Yahoo 分钟通道。历史仍依赖 Yahoo，限流或网络问题可能导致无法加载 |
| 场外基金 | AKShare → 天天基金 | 已公布单位净值、净值日期；没有盘中官方实时净值 |

免费来源没有稳定性、时延或永久可用保证。yfinance 是非官方工具，面向个人研究，实际数据使用须遵循 [Yahoo 条款及项目说明](https://ranaroussi.github.io/yfinance/)。AKShare 文档：[股票](https://akshare.akfamily.xyz/data/stock/stock_quote.html)、[基金](https://akshare.akfamily.xyz/data/fund/fund_public.html)。

5 秒是请求完成后的目标轮询间隔，另有请求耗时与最多约 2 秒的页面收集等待；并不保证每 5 秒出现新价格，也不是接口供应商承诺的免费额度。2026-10-29 对腾讯 SPY 报价做三轮间隔 5 秒的轻量实测均成功，不能据此保证长期不限流。Yahoo 曾返回 429，不适合依赖其进行高频轮询。场外基金公布单位净值，至少缓存 5 分钟，避免每 5 秒重新下载；手动更新仍可主动请求。

「行情来源与刷新状态」可查看每个产品的实际来源、源时间、本机获取时间和失败原因。美国源时间按纽约时区解释（含夏令时），页面转换为北京时间；港股源时间按香港时区。美股未开盘时，显示上一交易日收盘附近的快照属于正常情况，不能用本机刷新时间替代成交/源时间。

腾讯报价请求采用局部直连，不继承可能失效的海外 HTTP 代理，也不改变系统代理；原数据源请求仍沿用其进程环境。无匹配、错证券代码、无效价格或无效时间不会冒充成功结果。新增快照通道仅用于报价，未把其价格拼入历史序列。

**分析口径：** 区间涨跌幅为末价格 / 首价格 − 1；回撤相对于区间内历史最高价；波动率按日收益标准差 × √252 估算。原始价格、基金单位净值未计分红再投，不能直接等同投资总收益。短区间、不同市场交易日历和停牌会影响解读。成交量单位：境内股票/ETF 为手，Yahoo 为股。

## 缓存与隐私

- `data/market.sqlite` 保存真实自选和行情；`data/demo.sqlite` 保存演示自选。演示价格不写入真实缓存。
- `STOCKEASY_DATA_DIR` 可指定本地数据目录，`STOCKEASY_DEMO=1` 可用于离线演示启动。
- 股票/ETF 行情缓存随自动刷新间隔到期（暂停时为 60 秒），场外基金净值缓存至少 5 分钟，历史缓存 1 小时；「刷新」可主动更新。上游响应超过所选间隔时会顺延，不保证逐笔实时行情。原始历史更新最近 7 天，向前扩展时下载更早区间；复权序列更新时重载整个已缓存范围，避免拼接不同时点口径。
- 上游请求在独立进程运行，25 秒强制截止。失败不会伪造行情或自动切换到演示。
- 行情与历史筛选均在有界后台线程中调用请求进程，页面不等待慢接口。行情 UI 每 2 秒收集完成结果，网络刷新间隔从上次请求结果被收集时算起；失败后至少等待 30 秒再自动重试，点击更新可立即重试已完成的请求。正在进行的请求不重复发起，也不丢掉刚完成但尚未收集的结果。暂停时只收集已发出的请求和首次获取新加的产品，不重复发起定时查询。
- 页面在北京时间跨午夜时自动更新日期与当日筛选范围。
- 本地数据库、虚拟环境、密钥和下载数据均被 `.gitignore` 排除。服务默认只监听本机 `127.0.0.1`。
- 没有交易接口，也不读取券商账户。

如果遇到连接失败，先检查本机网络和代理配置，稍后再试。演示模式可离线体验所有主要界面。

## 推荐规则与范围

基础观察池有 12 个产品，另合并当前自选；这不是全市场扫描。推荐只基于复权日线/基金单位净值；少于 30 个有效数据点、价格日期超过 7 个自然日、未来日期或刷新失败回退的历史不入选。无匹配就留空，不为凑数量推荐。

| 类型 | 条件 |
| --- | --- |
| 趋势延续 | 20 日涨幅 >2%，价格在向上的 20 日均线上方 |
| 量能变化 | 最新成交量 ≥ 前 20 日平均成交量的 1.5 倍；缺失成交量不计算 |
| 回撤修复 | 距近 60 日高点仍回撤 ≥5%，最近 5 日回升 ≥1.5% |
| 低波动 | 近 60 日年化波动 <18%，当前回撤 <8% |

不足 60 个数据点时使用实际可用记录；日线可能早于今天。波动率按日收益标准差 × √252。规则仅用于解释历史信号，不代表买入建议、未来收益或全市场优选；放量不代表上涨，低波动不代表低风险。
